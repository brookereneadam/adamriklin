# אתר אדם ריקלין

אתר סטטי (HTML/CSS/JS) – מתארח בחינם ב-GitHub Pages.

## עדכונים נפוצים
- **מספר וואטסאפ:** `js/config.js`
- **הוספת אירוע:** `js/events-data.js` – להעתיק בלוק קיים ולשנות פרטים.
- **טקסטים:** `index.html`, `contact.html`
- **תמונה:** לשים קובץ ב-`images/` ולעדכן את `.portrait` ב-`index.html`.
