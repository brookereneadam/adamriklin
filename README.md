# אתר אדם ריקלין

אתר סטטי (HTML/CSS/JS) – מתארח בחינם ב-GitHub Pages.

## עמודים
- `index.html` – בית, אודות, שירותים
- `course.html` – קורס מבוא לבודהיזם (מחזורים חיים + קורס מוקלט)
- `events.html` – לוח אירועים והרשמה
- `contact.html` – טופס פנייה

## עדכונים נפוצים
- **וואטסאפ / גיליון / קישור תשלום:** `js/config.js`
- **הוספת אירוע:** `js/events-data.js`
- **הוספת מחזור קורס:** `js/courses-data.js`
- **חיבור ל-Google Sheets:** `google-sheets/SETUP.md`
